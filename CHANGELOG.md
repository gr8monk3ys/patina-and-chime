# Changelog

## 0.1.3

### Added

- A Block of Amethyst crafts into 4 amethyst shards. Four shards already make a block in vanilla, so it now works both ways.

## 0.1.2

### Fixed

- Every recipe now unlocks in the recipe book.
- An oxidized hopper's tooltip no longer says it keeps aging.
- An exposed hopper no longer picks up items lying on a chest above it.
- A pull that doesn't fit no longer changes the container above.
- Copper hoppers now move items to and from machines that use Fabric's item storage, and a full pipe testing one no longer stops it.
- Music no longer slows budding amethyst that another mod has sped up, and no longer shows its note particles where it changes nothing.
- The mod now asks for Fabric API 0.161.0 or newer, so the loader names the problem when it's older.
- The enchanting table change no longer relies on a name the compiler generates, so it won't break on a rebuilt game.
